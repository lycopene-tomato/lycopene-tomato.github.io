A solo developer's decision log

スマホだけで、アプリを
作って、届けて、運用する。

手元に Mac も PC もありません。iPhone と、クラウドの向こうの Claude・GitHub・EAS。lycoapp.com のアプリ群を一人で作る中の意思決定を、ADR (Architecture Decision Record) として残しています。

TL;DR

  • lycoapp.com の全アプリは iPhone だけで開発している (手元に Mac なし)
  • 構成は Claude Code on Web + GitHub + EAS。固定費は Claude Pro $20/月 と Apple Developer Program $99/年
  • 各記事は ADR。MADR × SCQA 形式で「なぜそう決めたか」だけを書く
  • このサイトは個人情報を収集しない。広告もない

Policy — このサイトの方針

個人情報を集めないアクセス解析なし。cookie バナーなし。フォームなし。読むだけのサイトです。
広告を貼らない記事に広告は載せません。支援は Buy Me a Coffee の1本だけ。
一人 + AI で作る開発もこのサイトも、一人の開発者と AI の協働で作っています。
実際に動いた構成だけ構築して運用まで通ったものだけを ADR として残します。机上の比較記事は書きません。

FAQ

このサイトは何ですか?

lycoapp.com のアプリ群を一人で作る中での意思決定を ADR (Architecture Decision Record) として残した開発ログです。手順書ではなく「なぜそう決めたか」を書いています。

誰が書いていますか?

Lyco App の開発者本人です。フルタイムで働きながら、育児の隙間時間にスマホだけで開発しています。プロフィールは About にあります。

詳細な手順は載っていますか?

載せていません。ADR なので、判断の理由と構成が主です。再現したい場合は、記事を AI に渡して手順を聞くのが早いです。実際に動いた構成であることは確認済みです。

本家 lycoapp.com との関係は?

同じ開発者・同じドメインです。本家は子どもの習慣づくりアプリの世界、こちらはその開発の裏側です。読者が違うので、デザインを意図的に分けています。
